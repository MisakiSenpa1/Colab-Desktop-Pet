# 桌宠立绘目录说明

本目录现已随附一套开箱即用的四表情 Q 版透明 WebP 立绘（由 `1200 × 1004` RGBA 原图无损 Alpha 压缩，带 `#221F52` 深靛蓝描边且四帧外轮廓像素级对齐）与预构建图标/遮罩，授权与非商业使用边界详见 [../ASSETS_NOTICE.txt](../ASSETS_NOTICE.txt)。

## 内置文件说明

- `idle.webp`：常驻待机表情
- `blink.webp`：定时眨眼表情
- `proud.webp`：互动/低耗/心情愉悦表情
- `sad.webp`：报错/算力告急警示表情
- `pet.ico`：多尺寸 Windows 应用与打包图标
- `alpha_masks.json`：预提取的 `500 × 418` 不规则窗口裁剪二值轮廓遮罩（零 Pillow 运行期加载）

## 自定义替换或矢量兜底模式

1. **自定义立绘**：可直接覆盖以上 4 张透明背景 RGBA `.webp`（或同名前缀 `.png`）图片（建议尺寸 `1000 × 836` 以上、宽高比约 `1.2 : 1`，并让 `proud` / `sad` 与 `idle` 保持相同的外轮廓且带深靛蓝描边，以免触发 Win32 边缘穿帮）；若替换轮廓形状，请同步更新 `alpha_masks.json` 或删除它以使用矩形圆角兜底区域。
2. **极简矢量兜底模式**：若删除这 4 张立绘文件，`win32_window.py` 会在内存中自动生成原创极简矢量角色（同样支持 `idle` / `blink` / `proud` / `sad` 四种表情），仍可零依赖正常启动桌宠。
