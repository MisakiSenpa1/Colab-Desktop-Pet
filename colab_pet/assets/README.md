# 桌宠立绘目录说明

遵循 [../ASSETS_NOTICE.txt](../ASSETS_NOTICE.txt) 的版权声明，本公开仓库不随附第三方人物立绘 PNG 素材。

## 两种使用方式

1. **开箱即用（默认兜底模式）**：未放入图片时，`pet_app.py` 会在内存中自动生成原创极简矢量小人（支持 `idle` / `blink` / `proud` / `sad` 四种表情与真实不规则 Alpha 边缘裁剪），可零配置直接启动桌宠。
2. **替换为自定义立绘**：在本目录放入以下 4 张透明背景 RGBA PNG 图片（推荐尺寸 `500 × 418`，轮廓建议带 `#221F52` 深靛蓝描边以获得最佳融合效果）：
   - `idle.png`：常驻待机表情
   - `blink.png`：定时眨眼表情
   - `proud.png`：互动/低耗/心情愉悦表情
   - `sad.png`：报错/算力告急警示表情

> 注意：`.gitignore` 已默认忽略本目录下的图片文件，避免误将受版权限制的个人素材提交到公共仓库。
