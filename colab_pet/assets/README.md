# 桌宠立绘目录说明

本目录现已随附一套开箱即用的四表情 Q 版透明 PNG 立绘（`1200 × 1004` RGBA，带 `#221F52` 深靛蓝描边，且四帧外轮廓像素级对齐以适配 Win32 不规则窗口裁剪），授权与非商业使用边界详见 [../ASSETS_NOTICE.txt](../ASSETS_NOTICE.txt)。

## 内置文件说明

- `idle.png`：常驻待机表情
- `blink.png`：定时眨眼表情
- `proud.png`：互动/低耗/心情愉悦表情
- `sad.png`：报错/算力告急警示表情

## 自定义替换或矢量兜底模式

1. **自定义立绘**：可直接覆盖以上 4 张透明背景 RGBA PNG 图片（建议尺寸 `1000 × 836` 以上、宽高比约 `1.2 : 1`，并让 `proud.png` / `sad.png` 与 `idle.png` 保持相同的外轮廓且带深靛蓝描边，以免触发 Win32 边缘穿帮）。
2. **极简矢量兜底模式**：若删除这 4 张 `.png` 文件，`pet_app.py` 会在内存中自动生成原创极简矢量角色（同样支持 `idle` / `blink` / `proud` / `sad` 四种表情与实时不规则 Alpha 边缘裁剪），仍可零依赖正常启动桌宠。
